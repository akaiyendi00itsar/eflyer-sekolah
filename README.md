# E-Flyer Sekolah

Aplikasi web untuk membuat e-flyer promosi sekolah dengan cepat.

**Buka aplikasi:** https://akaiyendi00itsar.github.io/eflyer-sekolah/

## Fitur
- Isi identitas sekolah sesuai data dinas/Dapodik (NPSN, jenjang, status, akreditasi, alamat lengkap, kontak).
- Dua tujuan flyer: **penerimaan siswa baru** (SPMB/PPDB/PPSB) atau **promosi kegiatan sekolah**.
- Tambah logo sekolah, gambar latar, dan backsound (musik bawaan atau file sendiri).
- Ukuran Feed Instagram 1:1, Story/Reels/WhatsApp 9:16, atau poster A4.
- Hasil berupa gambar PNG, video beranimasi dengan musik, dan caption media sosial otomatis.

Semua proses berjalan di peramban; data dan file tidak dikirim ke server mana pun.
